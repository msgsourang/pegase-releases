# Pegase by ZEPHYR

Téléchargez la dernière version : **[Releases → Latest](https://github.com/msgsourang/pegase-releases/releases/latest)**

| Système | Fichier |
|---|---|
| Windows 10 / 11 | `PegaseSetup.exe` |
| macOS 13 et plus récent (Mac Intel ou Apple) | `Pegase-<version>.dmg` (ou `.pkg`) |

**Première ouverture sur Mac** : clic droit sur Pegase → **Ouvrir**. Sur macOS 15 et plus récent : Réglages Système → Confidentialité et sécurité → **Ouvrir quand même**.

**Mises à jour** : Pegase vérifie chaque jour s'il existe une nouvelle version et vous la propose. Vos profils, favoris, mots de passe et mails sont conservés.

Ce dépôt ne contient que les installateurs. Le code source de Pegase est privé.
